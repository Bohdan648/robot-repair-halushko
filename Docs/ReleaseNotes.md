# Опис релізу

Тег: `v1.0.0`. Назва: **Аварійний двір — 1.0.0**.

Текст для GitHub Release:

> Коротка 2D-гра, у якій треба полагодити трьох роботів, обійти небезпечні розливи
> й зберегти здоров’я. Синя плита відчиняє короткий прохід на 4 секунди, а довший
> обхід доступний завжди. У версії 1.0.0 додано стартовий екран, звуки удару,
> лікування й ремонту та збільшено текст HUD.

Публікувати після перевірки виконуваної версії.
Прикріпити ZIP, створений командою **Robot Repair → Build Windows ZIP**.
Користувач розпаковує його повністю та запускає AvariinyiDvir.exe.
