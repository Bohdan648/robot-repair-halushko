### 04.10.2026 — Юніт 2: оточення і фізика

**Що зроблено:**
* Намальовано нову карту з суцільним цегляним бордюром по периметру та водоймами.
* Налаштовано фізику руху персонажа через `Rigidbody2D.MovePosition()` у методі `FixedUpdate()`.
* Налаштовано 2D-колайдери для префабів дерев (`Decoration_5`, `Decoration_8`) строго за основою стовбура.
* Налаштовано правильну глибину та Z-sorting: встановлено `Sprite Sort Point = Pivot` для дерев та `Order in Layer = -1` для пасток `DamageZone`.
* Налаштовано непрохідність води та бордюру за допомогою `Tilemap Collider 2D` та `Composite Collider 2D`.

**Що не вийшло або забрало найбільше часу:**
* Виправлення помилки з додаванням 3D `Box Collider` замість 2D-версії для великого дерева.
* Пошук причин тремтіння персонажа при зіткненнях із перешкодами під час руху через `Update()`.
* Розібратися з новими налаштуваннями Unity 6 для `Tilemap Collider 2D` (`Composite Operation: Merge` замість старого прапорця `Used By Composite`).

**Що зрозумів про FixedUpdate і колайдери:**
* `Update()` залежить від FPS, тому рух через `transform.position` викликав конфлікт із фізичним рушієм і тремтіння. `FixedUpdate()` працює з фіксованим кроком часу, а `MovePosition()` переміщує об'єкт плавно без "прошивання" колайдерів.
* Для тайлів підлоги й трави обов'язково потрібен `Collider Type = None`, інакше вся карта стане однією великою стіною і персонаж не зможе рухатися.

**Що в рівні вийшло не так, як у фізичному паспорті, і чому:**
* Конфігурацію та форму карти було повністю перероблено на прямокутну із суцільним цегляним бордюром по периметру. Це було зроблено для того, щоб гарантовано закрити межі екрана камери, запобігти виходу персонажа за межі світової зони та усунути візуальну порожнечу навколо карти.
