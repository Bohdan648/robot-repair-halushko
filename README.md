**Що зрозумів про тригери, public і private:** 
* **Тригери (`Is Trigger`):** фіксують події дотику та перебування в зоні без фізичного відштовхування об'єктів.
* **`public`:** надає доступ іншим скриптам та виводить змінні в Inspector Unity.
* **`private`:** захищає внутрішні дані (наприклад, `currentHealth`) від випадкових змін ззовні.

**Яке значення Time Invincible обрав і для якого гравця:** 
Обрав **2.0 секунди** (`timeInvincible = 2.0f`). Це комфортний інтервал для звичайного (casual) гравця, який дає достатньо часу для реакції та відбігання від небезпечної зони.
